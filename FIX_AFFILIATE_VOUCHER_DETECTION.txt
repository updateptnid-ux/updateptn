============================================
FIX AFFILIATE VOUCHER NOT DETECTED
============================================

MASALAH:
--------
Kode affiliate (contoh: PTN-B17F4D) tidak terdeteksi saat checkout.
Error: "Kode voucher tidak ditemukan atau tidak valid!"

ROOT CAUSE:
-----------
1. Affiliate yang dibuat SEBELUM fitur auto-generate code ditambahkan
   → affiliate_code mereka masih NULL atau kosong
2. Auto-generate code baru jalan untuk affiliate yang di-approve SETELAH update

SOLUSI:
-------
Run SQL script di Supabase SQL Editor untuk generate code untuk affiliate lama:

```sql
-- File: supabase/FIX_MISSING_AFFILIATE_CODES.sql

UPDATE public.affiliates
SET 
  affiliate_code = generate_affiliate_code(),
  updated_at = NOW()
WHERE 
  status = 'active' 
  AND (affiliate_code IS NULL OR affiliate_code = '');
```

CARA PAKAI:
-----------
1. Buka Supabase Dashboard → SQL Editor
2. Copy-paste script di atas
3. Klik "Run" atau Ctrl+Enter
4. Check hasil:

```sql
SELECT 
  id,
  full_name,
  email,
  affiliate_code,  -- Harusnya udah ada code PTN-XXXXXX
  status,
  approved_at
FROM public.affiliates
WHERE status = 'active'
ORDER BY approved_at DESC;
```

EXPECTED RESULT:
----------------
Semua affiliate active sekarang punya `affiliate_code`:
- PTN-ABC123
- PTN-XYZ789
- PTN-B17F4D
- dll.
